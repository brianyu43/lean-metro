# Lean Metro v1.3 telescoping plan

## 1. 목표와 판정 기준

v1.2는 finite irreducibility에서 `MeanZeroPoissonInvertible`을 자동으로
생성한다. 그러나 실제 sample-mean asymptotic variance 정리는 여전히 각
kernel에 대해 pointwise Poisson-covariance decay를 입력으로 받는다.

v1.3의 우선 목표는 spectral decay를 먼저 형식화하는 것이 아니다. 현재
증명된 exact Cesàro remainder에 Poisson equation과 reversibility를 적용하여
decay 가정을 제거할 수 있는지 먼저 닫는다.

성공 시 최종 수학적 사슬은 다음과 같다.

\[
\begin{aligned}
&\text{finite irreducibility}
  \Longrightarrow (I-P)|_{L^2_0(\pi)}^{-1}\text{ exists},\\
&\text{reversibility} + (I-P)g=f
  \Longrightarrow
  \langle f,P^k g\rangle_\pi=c_k-c_{k+1},\\
&\text{finite stochasticity}
  \Longrightarrow (c_k)_k\text{ is uniformly bounded},\\
&\text{therefore }
  \frac{1}{N}\sum_{k=1}^{N}\langle f,P^k g\rangle_\pi
  \longrightarrow 0.
\end{aligned}
\]

여기서 `c k = weightedInner π g (markovIterate P k g)`이다.

완료 기준은 다음과 같다.

- 기존 pointwise `hdecay` 없이 reversible finite kernel의
  `stationaryScaledVariance` limit을 증명한다.
- 이를 실제 finite-path sample-mean variance limit까지 연결한다.
- MH와 admissible competitor의 irreducibility만 받는 public wrapper를 만든다.
- 2상태 concrete example이 새 wrapper를 직접 호출하며 수동 `hinv`와
  `hdecay` 전달을 모두 제거한다.
- concrete end-to-end theorem까지 `#print axioms`로 고정한다.

기존 decay 기반 정리는 삭제하지 않는다. pointwise decay 자체와 spectral
rate를 연구할 때 여전히 더 강하고 유용한 API이므로 호환 레이어로 유지한다.

## 2. 가정의 정확한 경계

### 2.1 Decay-free variance limit

generic telescoping theorem에서 필요한 가정은 다음과 같다.

- `ι`는 finite state space이다: `[Fintype ι]`.
- `P : FiniteKernel ι`이므로 transition은 nonnegative이고 각 행의 합은 1이다.
- `P.ReversibleFor π`가 성립한다. 이는 weighted pairing에서 `P`의
  self-adjointness와 stationarity를 준다.
- `MeanZeroPoissonInvertible π P`가 주어지고 `MeanZero π f`이다.

`stationaryScaledVariance` 자체의 극한에는 `π`의 nonnegativity나
normalization도 필요하지 않다. uniform bound가 `∑ x, |π x * g x|`를
사용하기 때문이다. 반면 실제 sample-mean theorem에서는 `π`가 probability
mass가 되어야 하므로 nonnegativity와 normalization을 모두 받는다.

중요하게도 이 단계에는 irreducibility와 aperiodicity가 직접 필요하지 않다.
irreducibility는 Poisson inverse를 자동 생성하는 한 가지 충분조건이다.
aperiodicity는 `P^n g -> 0` 같은 pointwise decay에는 필요할 수 있지만,
이번 목표인 bounded telescoping remainder에는 필요하지 않다.

### 2.2 Irreducibility-facing Peskun wrapper

최종 MH wrapper는 다음을 받는다.

- positive target weights `w`;
- nonnegative row-stochastic proposal `q`;
- `AdmissibleAcceptance w q a`인 competitor acceptance `a`;
- 생성된 MH kernel과 competitor kernel 각각의 finite irreducibility;
- normalized target에 대해 centered인 observable `f`.

일반 admissible competitor는 accepted moves를 0으로 만들 수 있으므로 MH
kernel의 irreducibility만으로 competitor irreducibility가 자동으로 따라오지
않는다. 따라서 두 irreducibility 가정은 별도로 받는 것이 정확하다.

wrapper는 reversibility와 stationarity는 기존 MH/admissibility 정리에서,
Poisson inverse는 v1.2 irreducibility adapter에서, variance limit은 이번
telescoping theorem에서 내부적으로 생성한다. public 호출자는 `hinvMH`,
`hinvA`, `hdecayMH`, `hdecayA`를 넘기지 않는다.

## 3. 증명 사다리

### Stage A — 망원합 항등식과 인덱스 검증

먼저 새로운 limit 전술 없이 유한 `n`에 대한 정확한 항등식만 증명한다.

`g`가 `PoissonEquation P f g`, 즉 `f = g - Pg`를 만족하고 `P`가
`π`에 대해 reversible이라고 하자. 다음 helper를 목표로 한다.

```lean
theorem weightedInner_poisson_markovIterate_eq_sub
    (hrev : P.ReversibleFor π)
    (hpoisson : PoissonEquation P f g) (k : ℕ) :
    weightedInner π f (markovIterate P k g) =
      weightedInner π g (markovIterate P k g) -
      weightedInner π g (markovIterate P (k + 1) g)
```

증명은 다음 세 사실만 사용한다.

1. `f = g - Pg`인 Poisson equation;
2. `weightedInner_markovOperator_selfAdjoint`;
3. `markovIterate_succ`가 주는 `P(P^k g)=P^(k+1)g`.

그다음 `c k = weightedInner π g (markovIterate P k g)`로 놓고 기존
`sum_shifted_sub`를 재사용하여 정확히 다음을 확인한다.

```text
sum k in range (n + 1), <f, P^(k + 1) g>_π
  = c 1 - c (n + 2)
```

현재 `stationaryScaledVariance_eq_algebraic_sub_remainder`의 입력 `n`은
표본 크기 `N = n + 1`을 뜻한다. remainder는 `range (n + 1)`에서 lag
`k + 1`을 합하므로 끝 인덱스는 `c (n + 2)`, 즉 `c (N + 1)`이다.
이 off-by-one을 theorem statement와 주석에서 고정한다.

Stage A gate:

- 임의의 `n`에 대한 pointwise identity가 독립 컴파일된다.
- `n = 0, 1, 2`를 `simp` 또는 작은 regression lemma로 확인한다.
- 아직 `Tendsto`나 boundedness를 섞지 않는다.

### Stage B — finite Markov iterate의 uniform bound

`max` API에 의존하지 않고 finite sum-of-absolute-values를 bound 상수로
사용한다.

```lean
noncomputable def functionAbsSum (g : ι → ℝ) : ℝ :=
  ∑ x, |g x|
```

증명 순서는 다음과 같다.

1. `|g x| <= functionAbsSum g`.
2. 모든 `x`에서 `|h x| <= C`이고 `0 <= C`이면
   `|markovOperator P h x| <= C`.
   이는 triangle inequality, `P.nonneg`, `P.row_sum`으로 증명한다.
3. 귀납법으로 모든 `n, x`에 대해
   `|markovIterate P n g x| <= functionAbsSum g`.
4. 임의의 finite weight `π`에 대해
   `|weightedInner π g (markovIterate P n g)|`를 `n`과 무관한 finite
   constant로 bound한다. 예를 들면

   \[
   \left|\langle g,P^n g\rangle_\pi\right|
   \le
   \left(\sum_x |\pi(x)g(x)|\right)
   \left(\sum_y |g(y)|\right).
   \]

이 단계의 핵심은 `P^n g`가 수렴함을 보이는 것이 아니라 bounded임만
보이는 것이다. periodic kernel도 통과해야 한다.

Stage B gate:

- bound의 우변에 `n`이 나타나지 않는다.
- aperiodicity, irreducibility, spectral theorem을 import하지 않는다.
- `π` normalization이 실제로 필요하지 않다면 helper에는 넣지 않고,
  상위 probability theorem에서만 추가한다.

### Stage C — decay-free `stationaryScaledVariance` limit

Stage A를 기존 exact remainder에 대입하여 다음 유한시간 공식을 먼저
만든다.

\[
V_n
=
\sigma^2_{\mathrm{alg}}
-
\frac{2}{n+1}\left(c_1-c_{n+2}\right).
\]

그다음 Stage B의 uniform bound와 `(n + 1 : ℝ)⁻¹ -> 0`을 결합한다.
목표 public theorem은 다음 형태다.

```lean
theorem stationaryScaledVariance_tendsto_of_reversible
    (hrev : P.ReversibleFor π)
    (hinv : MeanZeroPoissonInvertible π P)
    (f : ι → ℝ) (hf : MeanZero π f) :
    Tendsto (stationaryScaledVariance π P f) atTop
      (𝓝 (algebraicAsymptoticVariance π P hinv f hf))
```

정확한 Lean 구현에서는 기존 명명 규칙에 맞춰 이름을 조정할 수 있지만,
`hdecay` 인자가 없어야 한다.

Stage C gate:

- period-2 kernel처럼 `P^n g`가 진동할 수 있는 경우에도 theorem이 적용된다.
- 기존
  `stationaryScaledVariance_tendsto_algebraicAsymptoticVariance`는 유지한다.
- 새 proof가 기존 `hdecay` theorem을 우회하고 exact finite-time identity에서
  직접 출발함을 theorem map에 기록한다.

### Stage D — 실제 finite-path sample-mean variance bridge

기존 `chainSampleMean_scaledVariance_eq`와 Stage C를 합성한다.

```lean
theorem chainSampleMean_scaledVariance_tendsto_of_reversible
    (hπ_nonneg : ∀ x, 0 ≤ π x)
    (hπ_sum : ∑ x, π x = 1)
    (hrev : P.ReversibleFor π)
    (hinv : MeanZeroPoissonInvertible π P)
    (f : ι → ℝ) (hf : MeanZero π f) :
    Tendsto
      (fun n => ((n + 1 : ℕ) : ℝ) *
        variance (chainSampleMean f n)
          (stationaryPathMeasure π P hπ_nonneg hπ_sum n))
      atTop
      (𝓝 (algebraicAsymptoticVariance π P hinv f hf))
```

`hstat`는 별도 인자로 받지 않고 `hrev.stationary`로 공급한다. 같은 내용을
`HasSampleMeanAsymptoticVariance`로 감싼
`hasSampleMeanAsymptoticVariance_of_reversible`도 추가한다.

Stage D gate:

- theorem이 mathlib의 실제 `ProbabilityTheory.variance`와 기존
  finite-path probability measure를 사용한다.
- `hdecay`와 aperiodicity가 signature에 없다.
- 기존 decay 기반 bridge는 backward-compatible theorem으로 남는다.

### Stage E — irreducibility-facing MH-vs-competitor wrapper

두 generated kernel에 대해 다음을 내부에서 구성한다.

1. 기존 reversibility 정리;
2. reversibility에서 stationarity;
3. `normalizedWeight_sum`;
4. `meanZeroPoissonInvertible_of_irreducible`;
5. Stage D의 decay-free actual variance limits;
6. 기존 algebraic Peskun ordering.

목표 theorem 이름은 다음과 같다.

```lean
metropolisHastings_minimizes_sampleMeanAsymptoticVariance_of_irreducible
```

핵심 signature에는 두 generated kernel의 `Irreducible` 증명만 새로 있고
`hinv*`와 `hdecay*`는 없어야 한다. 결과는 기존 crown theorem처럼 두 actual
limits와 그 ordering을 돌려주되, 내부에서 만든 inverse가 type에 지나치게
노출되면 다음의 간결한 corollary도 제공한다.

```lean
∃ σMH σA,
  HasSampleMeanAsymptoticVariance ... σMH ∧
  HasSampleMeanAsymptoticVariance ... σA ∧
  σMH ≤ σA
```

Stage E gate:

- public 호출자가 standard finite-state assumptions만 제공한다.
- competitor irreducibility를 몰래 MH irreducibility에서 도출하지 않는다.
- 기존 conditional crown theorem도 저수준 API로 유지한다.

### Stage F — direct end-to-end regression example

`CrownExample.lean`의 동일한 target, proposal, half-MH competitor를 유지하되
새 wrapper를 직접 호출하는 theorem을 추가한다.

검증할 경로는 다음과 같다.

```text
concrete w, q, a
  -> admissibility
  -> both generated kernels irreducible
  -> automatic Poisson inverses
  -> decay-free reversible variance limits
  -> probabilistic Peskun wrapper
  -> actual limits 3/2 and 6
  -> 3/2 <= 6
```

기존 수동 covariance formula와 pointwise decay example은 삭제하지 않는다.
이는 새 theorem이 더 약한 가정으로 같은 결론을 얻는다는 비교 자료이자
spectral behavior를 설명하는 교육용 회귀 예제다.

Stage F gate:

- 새 concrete theorem의 proof term에 수동 `hinv`와 `hdecay` theorem이 없다.
- 최종 결론은 실제 `HasSampleMeanAsymptoticVariance` 두 개와 `3/2 <= 6`이다.
- 전체 wrapper API가 바뀌면 이 예제가 compile failure로 즉시 감지한다.

### Stage G — end-to-end axiom audit

현재 `LeanMetro/AxiomAudit.lean`은
`LeanMetro.ProbabilisticPeskun`만 import하고 일반 crown theorem 하나만
감사한다.

```lean
#print axioms
  metropolisHastings_minimizes_sampleMeanAsymptoticVariance
```

그 결과는 현재 `[propext, Classical.choice, Quot.sound]`로 고정되어 있다.
이 audit은 일반 crown theorem보다 뒤에 있는 irreducibility adapter와
concrete example의 의존성까지는 추적하지 않는다.

v1.3에서는 `AxiomAudit.lean`이 새 concrete theorem을 볼 수 있도록
`CrownExample` 또는 해당 end-to-end module을 import하고, 별도의
`#guard_msgs in #print axioms` 블록을 추가한다.

```lean
#print axioms two_state_crown_actual_limits_and_order_of_irreducible
```

정확한 expected message는 구현 후 Lean이 실제 출력한 표준 axiom set을
확인한 뒤 고정한다. 허용 대상은 Lean의 표준 extensionality, classical
choice, quotient soundness 계열뿐이며 `sorryAx` 또는 프로젝트 고유 axiom이
하나라도 나타나면 release를 중단한다. 기존 일반 crown audit도 함께 유지하여
저수준 API와 end-to-end API를 각각 감사한다.

Stage G gate:

- 일반 crown theorem과 concrete irreducibility-facing theorem의 guard가
  모두 독립적으로 컴파일된다.
- CI가 `lake env lean LeanMetro/AxiomAudit.lean`을 별도 단계로 실행한다.
- expected axiom message 변화는 의도적인 감사 갱신 없이는 CI를 실패시킨다.

## 4. 실패 시 fallback과 중단 기준

망원합 경로는 수학적으로 단순해 보여도 Lean에서 실패 원인을 구분해야
한다.

### 4.1 먼저 해결할 형식화 문제

- self-adjointness lemma의 좌우 방향이 반대이면
  `weightedInner_comm`과 전용 helper로 방향을 맞춘다.
- `markovIterate`의 successor 방향이 맞지 않으면 semigroup/successor helper를
  먼저 증명한다.
- exact remainder와 telescope의 범위가 어긋나면 Stage A의 작은 `n`
  regression으로 인덱스를 수정한다.
- sup API가 과도하게 복잡하면 계획대로 `functionAbsSum`을 고정 상수로 써서
  convex-combination bound를 증명한다.
- `Tendsto` 자동화가 막히면 먼저
  `|remainder n| <= C / (n + 1)` 형태를 만들고 squeeze theorem으로 닫는다.

이 문제들은 spectral theorem으로 우회할 이유가 아니다.

### 4.2 수학적 statement가 그대로 닫히지 않을 때

1. reversibility 아래 lag별 difference identity를 독립 확인한다.
2. uniform bound와 exact range identity를 독립 확인한다.
3. 둘 중 하나가 실제로 더 강한 가정을 요구하면 그 가정을 helper 수준에서
   가장 작게 추가하고 theorem audit에 공개한다.
4. 직접 telescope 대신 다음의 중간 API를 허용한다.

```lean
CesaroPoissonRemainderVanishes π P hinv f hf
```

그리고 finite stochastic reversible kernel에서 이 averaged condition을
자동 생성한다. pointwise `hdecay`로 되돌아가지는 않는다.

period-2 finite reversible chain은 중요한 진단 예제다. 여기서 pointwise
covariance decay는 실패할 수 있지만 averaged remainder가 0으로 가야 한다.
이 예제에서도 새 theorem이 실패한다면 hidden assumption이나 인덱스 오류를
먼저 찾는다.

### 4.3 release 중단 기준

다음 중 하나라도 남으면 v1.3에서 “decay assumption removed”라고 주장하지
않는다.

- remainder가 exact telescope임을 유한 `n`에서 증명하지 못함;
- `c_n`의 uniform bound가 `n`에 의존함;
- wrapper가 여전히 `hdecay` 또는 동등한 pointwise convergence를 받음;
- concrete example이 새 wrapper를 직접 사용하지 않음;
- concrete axiom audit에 `sorryAx` 또는 비표준 프로젝트 axiom이 나타남.

이 경우 기존 v1.2 theorem과 API를 보존하고, 성공한 helper만 unreleased
development 결과로 남긴다. spectral adapter는 실제 수학적 필요가 확인될
때만 다음 milestone로 승격하며, 단지 Lean 전술이 어렵다는 이유로 먼저
도입하지 않는다.

## 6. v1.3 성공 후 남는 경계

telescoping이 성공해도 다음을 증명한 것은 아니다.

- `P^n g -> 0`의 pointwise 또는 norm convergence;
- spectral gap 또는 quantitative mixing rate;
- Markov-chain CLT나 분포수렴;
- 무한 path-space construction;
- general-state-space Markov kernels.
